# Matriz de trazabilidad

44 RF, 32 RNF y 32 historias de usuario. Cada requerimiento tiene al menos una historia y cada historia cubre al menos un requerimiento.

**Prioridad (MoSCoW):** M = Must, S = Should, C = Could.

**Estado:** *Implementado* = ya funciona en la app y tiene prueba automática o verificación en el navegador. *Parcial* = una parte funciona y el reporte dice qué falta. *Pendiente* = definido, todavía sin código. El estado se actualiza solo con `npm run reporte`.
